Pick Sheet Privacy Policy

Last updated November 1, 2026.

Pick Sheet is a private tool one online reseller runs on their own computer to see which sold items still need to ship. Only the owner's own Gmail accounts are connected to it.

What it reads

With Google's read-only Gmail permission, it searches the connected inboxes for sale emails from specific online marketplaces. It can't send, change or delete email.

What it saves

It saves only the sale details it pulls from those emails: item title, price, buyer name, order number, dates, and links to the order and item photo. The emails themselves aren't saved. These details stay on the owner's computer, along with the sign-in tokens that keep the Gmail connection working.

What it shares

Nothing. This information isn't sold, shared, or used for advertising, and it isn't sent to any other service. It's used only to show the owner's list of items to ship.

Google user data

Pick Sheet's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time from Google Account permissions. The saved details can be removed by deleting them from the owner's computer.

Contact

Questions can be sent through the owner's GitHub profile.
